04 / THE COMPLETE SCORE NULL
Flip within pairs.
Never shuffle task identities.
Each nonzero matched score difference is an integer number of .001 score ticks. Enumerate all 2^m sign assignments. Zero differences are factored out; their repeated assignments cancel from the probability. Sum and absolute-tail comparisons are exact bounded integers.
Two-sided p = count(|signed sum| ≥ |observed sum|) / 2^m, including ties. This is exhaustive, not Monte Carlo: no plus-one correction. No matched pairs is undefined. All ties produce one reduced assignment and p=1, not proof of equivalence.

06 / NO AUTOMATIC SCIENTIFIC VERDICT
Exact enumeration is not
an exact claim about the world.
The sign-flip interpretation needs independent pairs and exchangeable baseline/candidate labels within each pair under the null, or a defensible symmetric difference model. Repeated prompts, correlated examples, task selection, changed scorers and repeated model searches can invalidate that interpretation. The McNemar control likewise assumes independent paired binary observations.
A p-value is not the probability the null is true, a confidence interval, an effect-size guarantee, equivalence evidence or a license to ignore individual regressions. Multiple comparisons and reuse of a benchmark are not corrected here. There is no significance threshold, model ranking or automatic inference gate.
The original 68 tests, scorer/adapter task suite and demo remain unchanged. New controls expose cohort reversal, allowed declines, pass/score disagreement, missing and added tasks, binary64 boundaries and full null distributions. The original passing mock is retained beside a clearly labeled controlled replacement.
